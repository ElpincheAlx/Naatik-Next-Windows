# Na’atik Next 1.0 · Windows x64 · Español / English

Abre **Naatik-Next-1.0-Setup.exe**, elige idioma y pulsa **Instalar / reparar**.
Puedes cerrar la ventana antes de instalar. Necesita Internet para preparar Python
y las dependencias. Después abre **Na’atik Next** desde Inicio.

El tutorial guía OCR, traducción, diccionarios y Anki opcional. Las descargas de
recursos requieren confirmación. Omitir no instala nada; retoma desde Ayuda.
En **Configuración → Idioma** puedes cambiar el idioma para la próxima apertura,
sin cambiar OCR ni traducción. Reparar conserva preferencias y progreso.

**English:** open the Setup EXE, choose English and click Install / repair.
Internet is required for Python and dependencies. Open Na’atik Next from Start.
The tutorial guides optional resource preparation; downloads need confirmation.
Resume from Help. Settings → Language changes the next launch without changing
OCR/translation settings. Repair preserves profile data and tutorial progress.

El ZIP contiene las fuentes actualizadas y su README con instrucciones de
desarrollo. SHA256.txt permite comprobar la integridad. Lee VALIDACION.txt para
las pruebas reales y pendientes. La revisión visual fue offscreen; aún falta
validar instalación/reparación completas en Windows limpio y captura/atajos reales.
El instalador no está firmado digitalmente.
